# 🧮 Calculator (Python)

## 📌 Project Description
This is a simple Calculator application developed using Python.

The calculator performs basic arithmetic operations using a menu-driven approach and loops until the user chooses Exit.

## ✨ Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Exit Option
- Continuous execution using `while True`

## 🛠 Technologies Used
- Python

## 📂 Project Structure
```
calculator.py
README.md
```

## ▶️ How to Run

1. Install Python
2. Open terminal / command prompt
3. Navigate to project folder
4. Run:

```bash
python calculator.py
```
